THE RUBRIC (v1.1, P1-P6)
  2  directly relevant    The passage answers the question, or the part of it the passage could answer for a
                          multi-passage question. In a filing: it states the requested figure for the requested
                          period and company (including as a prior-year comparative column), or explains the
                          asked-about risk, policy or driver specifically.
  1  partially relevant   Useful but incomplete: right company, period and topic, only part of the answer. For
                          example a summary sentence without the requested figure, a table with the line item but
                          not the requested breakdown, or context needed to interpret the answer. A note is required.
  0  not relevant         Does not help answer the question: the same keywords in another context, a different
                          company, boilerplate.
  s  skip                 You looked but cannot decide: ambiguous scope, it needs knowledge you lack, or the passage
                          is cut mid-table. A skip is never a 0. A note is required.

  Rules
  - A skip is not a 0: use it whenever you would otherwise guess.
  - A cross-reference stub ("see Note 7") is 0 unless the question asks where the information is.
  - Repeated text is not assumed relevant: the same paragraph in another year's 10-K is 0 unless the question makes
    other years relevant.
  - Another filing can still hold the requested period, for example a later 10-K's prior-year column: grade it on
    that content.
  - Information about other years is 0, unless the question asks about a change or comparison it helps answer.
  - Multi-passage and cross-year questions: 2 if the passage supplies a required part (for example one requested
    year's figure), 1 if it only supports or interprets, 0 otherwise.

  Clarifications
  - P1, open questions (a set of risks, reasons, offerings...): a passage that explicitly states one element of the
    answer, for the requested company and period, is 2; it is 1 if it only names the topic, is cut off, or needs
    outside information.
  - P2, passage-alone evidence: for a figure, the requested period and basis must be identifiable from the passage
    itself (text, table headers, footnotes inside it). If the period or basis is defined only outside it, grade 1.
  - P3, comparatives: a later 10-K stating the requested figure for the requested period is graded on content: 2 if
    complete under P2, 1 if partial. Start the note with P3 and say what it shows.
  - P4, repeated text from another filing year: when the question names a report or year, another filing year's
    copy of a qualitative disclosure is 0, even verbatim. Start the note with P4 and name the year.
  - P5, closed multi-part questions: decide by the evidence. If no single filing can hold the whole answer, a
    passage with a complete required unit (the requested figures for at least one requested period) may be 2; if
    the full answer is normally in one table, a passage with only some of its elements is 1.
  - P6, notes and help: a note for every 1, every skip, every P3 and every P4 0. Do not use AI tools. If any other
    help was used for a grade (for example, you asked someone what a term means), start the note with ASSISTED and
    describe it.
