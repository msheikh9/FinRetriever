    Rubric v1.1 (P1–P6) and how to grade

    Grade each passage for the question as written, using the passage text alone. The filing and section shown help you locate it. Judge relevance, not truth.

    GradeMeaningIn a filing
    2 directly relevantThe passage answers the question, or the part of it the passage could answer for a multi-passage question.States the requested figure for the requested period and company (including as a prior-year comparative column), or explains the asked-about risk, policy or driver specifically.
    1 partially relevantUseful but incomplete: right company, period and topic, only part of the answer.A summary sentence without the requested figure; a table with the line item but not the requested breakdown; context needed to interpret the answer.
    0 not relevantDoes not help answer the question.Same keywords in another context; a different company; boilerplate.
    s skipYou looked but cannot decide. A skip is never a 0.Ambiguous scope, needs knowledge you lack, or the passage is cut mid-table. A note is required.

    Rules

    • A skip is not a 0: use it whenever you would otherwise guess.
    • A cross-reference stub ("see Note 7") is 0 unless the question asks where the information is.
    • Repeated text is not assumed relevant: the same paragraph in another year's 10-K is 0 unless the question makes other years relevant.
    • Another filing can still hold the requested period, for example a later 10-K's prior-year column: grade it on that content.
    • Information about other years is 0, unless the question asks about a change or comparison it helps answer.
    • Multi-passage and cross-year questions: 2 if the passage supplies a required part (for example one requested year's figure), 1 if it only supports or interprets, 0 otherwise.

    Clarifications P1–P6

    • P1, open questions (a set of risks, reasons, offerings…): a passage that explicitly states one element of the answer, for the requested company and period, is 2; it is 1 if it only names the topic, is cut off, or needs outside information.
    • P2, passage-alone evidence: for a figure, the requested period and basis must be identifiable from the passage itself (text, table headers, footnotes inside it). If the period or basis is defined only outside it, grade 1.
    • P3, comparatives: a later 10-K stating the requested figure for the requested period is graded on content: 2 if complete under P2, 1 if partial. Tick P3 and add a note.
    • P4, repeated text from another filing year: when the question names a report or year, another filing year's copy of a qualitative disclosure is 0, even verbatim. Tick P4 and add a note.
    • P5, closed multi-part questions: decide by the evidence. If no single filing can hold the whole answer, a passage with a complete required unit (the requested figures for at least one requested period) may be 2; if the full answer is normally in one table, a passage with only some of its elements is 1.
    • P6, notes and assistance: a note for every 1, every P4 0, every comparative and every skip. Record any help (an AI tool, a colleague) in the note, and tick "assistance".

    Keys

    2 1 0 grade · s skip · 3 P3 mark · 4 P4 mark · a assistance mark · n/→ next · p/← previous · u next ungraded.

    A grade that needs nothing more moves you to the next ungraded candidate. If it needs a note, the note box opens: type it, then press Ctrl/⌘+Enter to continue (Esc leaves the box). To mark P3 or P4, press 3 or 4 (or tick the box) before or after grading; keys are ignored while you type in the note box.

    Saving, resuming and returning

    • Every change is kept in this browser automatically. Reopen this same file in the same browser to continue.
    • Also press Save progress file regularly and keep the files: they let you resume on another computer or browser (Load progress file).
    • When every candidate of a question is graded (with the notes it needs), press Mark this question done.
    • When every question is done, press Download completed grades and send that file back unchanged.
    • Grade alone: no AI tools, no search summaries, no one else's grades.
