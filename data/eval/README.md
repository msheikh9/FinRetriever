# Evaluation data

Only empty placeholders remain here in the public repository (`gold_queries.jsonl`, `gold_qrels.jsonl`, used by
the benchmark harness's tests).

The evaluation records are kept in the project's private archive, because they name contributors whose
publication consent has not been confirmed:
- the development questions and their AI-written provisional labels (`dev_ai/`) and the label audits (`audit/`);
- the gold-set v1 human-annotation pilot (questions, grades, annotation packages and its closure record).

The results computed from them are in `results/` (passage IDs and metrics only). The README's limitations section
summarises what they can and cannot show.
