# Pilot audit review (`pilot_v1`) (withheld)

This record of a human audit of the AI-proposed development labels names its reviewer, a project contributor
whose publication consent has not been confirmed. It is **withheld from the public repository** and kept unchanged
in the project's private records. The development labels themselves (`data/eval/dev_ai/`) are withheld for the
same reason.

What it recorded, in summary: a human reviewer graded a sample of 30 AI-proposed labels. The development set
remains a set of 10 questions with AI-written provisional labels, and is not a human-labelled benchmark (see
[eval_methodology.md](eval_methodology.md) and the README's limitations section).
